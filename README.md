App Description: This app allows users to create an anime watchlist of animes they plan to watch for themselves. Users are able to search for any anime using the search bar. Once searched, all animes are displayed with relevant info that may persuade users to add it to their watchlist. To add to the watchlist, users simply click the "Add to Watchlist" buttom below the anime they want to add. When performing a search, the animes are fetched from the Jikan API. The watchlist itself is stored in MongoDB using mongoose.
